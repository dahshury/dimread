# Screenshots

README screenshots live here. Drop PNGs captured from the running app and
reference them from the root `README.md` (the `<!-- SCREENSHOTS -->` block).

Suggested set (mirrors the app's windows):

- `main.png` — the main quick-control panel (temperature + brightness sliders,
  presets, day/night, feature toggles).
- `tray-flyout.png` — the tray-anchored flyout with live sliders.
- `settings.png` — the settings window.
- `presets.png` — the preset mode grid.

Keep them on a consistent width (e.g. 840px for the hero, 100% inside tables)
so the README does not jump between sizes.
